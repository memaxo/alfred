# App Store Review Notes

## Demo Account

For testing purposes, no account is required. The app works entirely on-device.

## Test Instructions

1. **Launch the app** - App opens to chat screen
2. **Type a message** - Enter "Hello Alfred" and tap send
3. **Test voice input** - Tap microphone icon, speak, tap stop
4. **Navigate Library** - Tap Library tab to see Notes/Reminders/Timers/Bookmarks
5. **Create a note** - Go to Notes, tap +, type content, save
6. **Set a reminder** - Go to Reminders, tap +, set time, save
7. **Test offline** - Enable airplane mode, features work locally
8. **Test sync** - Disable airplane mode, data syncs automatically

## Privacy Practices

- **No tracking** - No third-party analytics or advertising
- **Local-first** - All data stored on device by default
- **Optional sync** - User controls when data is synced
- **No account required** - App works without sign-in

## Permissions Used

| Permission    | Usage                         |
| ------------- | ----------------------------- |
| Microphone    | Voice input for chat          |
| Notifications | Reminders and timers          |
| Network       | Optional sync and AI features |
