# Getting Started with ALFRED

Welcome! This guide will help you get ALFRED up and running quickly.

## Quick Start (5 minutes)

### Step 1: Install Prerequisites

- **Bun 1.2+** - [Install Bun](https://bun.sh)
- **Docker or Docker Desktop** - Required for PostgreSQL (`bun run db:start`)
- **PostgreSQL 16** with pgvector extension (runs via Docker)
- **Node.js 20+** (for tooling compatibility)
- **(Optional) UV** - [Install UV](https://github.com/astral-sh/uv) for Python dependency management (required for voice/embed packages)
- **(Optional) Python 3.10+** - Installed via UV for voice/embed packages
- **(Optional) poof** - For ephemeral filesystem isolation (Linux only): `bun run install:poof`

### Step 2: Clone and Install

\`\`\`bash
git clone <repo-url>
cd alfred
bun install
\`\`\`

### Step 3: Configure Environment

\`\`\`bash
cp config/env.example .env

# Generate auth keys

bun scripts/gen-keys.ts >> .env

# Edit .env with your settings

\`\`\`

**Minimum required settings:**

- `DATABASE_URL` - PostgreSQL connection string (default: `postgresql://alfred:alfred@localhost:5432/alfred`)
- `BETTER_AUTH_SECRET` - Generated by `bun scripts/gen-keys.ts` (already added above)
- `OPENAI_API_KEY` - Required for AI SDK v6 model access

### Step 4: Start Database

\`\`\`bash

# Ensure Docker is running (verify with: docker ps)

bun run db:start # Starts Postgres with pgvector

# Wait a few seconds for database to be ready, then:

bun run db:migrate # Applies migrations
\`\`\`

### Step 5: Start Development Server

\`\`\`bash
bun run dev # Starts web app + API
\`\`\`

### Step 6: Open Your Browser

Visit `http://localhost:3000` and you're ready to go!

### Optional: Enable Voice & Local Embeddings

**Voice Features:**
\`\`\`bash
cd packages/voice
bun run setup
\`\`\`

**Local Embeddings:**
\`\`\`bash
cd packages/embed
bun run install-deps
bun run download-model
\`\`\`

## Troubleshooting

### Common Installation Issues

**Docker/Database connection errors:**

- Verify Docker is running: `docker ps`
- Check `DATABASE_URL` in `.env` matches container settings
- Wait a few seconds after `db:start` before running `db:migrate`
- If you see `docker_compose_unavailable`, install Docker Desktop

**Missing environment variables:**

- Generate `BETTER_AUTH_SECRET`: `bun scripts/gen-keys.ts >> .env`
- Set `OPENAI_API_KEY` in `.env` (required for AI features)
- Verify keys are set: `grep -E "(BETTER_AUTH_SECRET|OPENAI_API_KEY|DATABASE_URL)" .env`

**Voice/embed features not working:**

- Install UV: `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Install voice dependencies: `cd packages/voice && bun run setup`
- Install embed dependencies: `cd packages/embed && bun run install-deps`
