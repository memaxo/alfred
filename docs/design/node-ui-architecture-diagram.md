## Data Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                    User Interaction                             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐

│  - onNodeClick ──► focusAndCenter(nodeId)                      │
│  - onNodesChange ──► applyNodeChanges()                         │
│  - onEdgesChange ──► applyEdgeChanges()                        │

                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Zustand Store Updates                              │

└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              React Flow Re-render                               │
│  - Nodes updated with new positions/data                        │

└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐

```

## Node Spawning Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                    Spawn Request                                │
│  - URL param: ?spawn=chat                                       │
│  - Command palette: "Create chat node"                          │
│  - Keyboard shortcut                                             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Spawn Type Validation                               │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Check if spawnType exists in nodeTypes                   │   │
│  │  └─ If not: toast.info("Node type not available")         │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Singleton Check                                     │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  if (singletonSpawnTypes.includes(spawnType)) {          │   │
│  │    const existing = nodes.find(n => n.type === spawnType)│   │
│  │    if (existing) {                                       │   │
│  │      focusAndCenter(existing.id)                         │   │

## RAG Document Caching Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                    RAG Document Request                          │
│  - URL param: ?ragDoc=<documentId>                              │
│  - Node click on knowledge node                                  │
│  - Context lens navigation                                       │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Cache Lookup                                        │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  const cachedEntry = ragDocCache[documentId]              │   │
│  │  const cachedRagDoc = cachedEntry &&                      │   │
│  │    Date.now() - cachedEntry.cachedAt < TTL                │   │
│  │      ? cachedEntry.data                                   │   │
│  │      : undefined                                          │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                    ┌─────────┴─────────┐
                    │                   │
                    ▼                   ▼
        ┌──────────────────┐  ┌──────────────────┐
        │  Cache Hit       │  │  Cache Miss      │
        └──────────────────┘  └──────────────────┘
                    │                   │
                    │                   ▼
                    │      ┌──────────────────────────────┐
                    │      │  Graph Query (tRPC)         │
                    │      │  trpc.graph.runQuery({       │
                    │      │    kind: "traverse",         │
                    │      │    nodeId: documentId,       │
                    │      │    direction: "both",        │
                    │      │    limit: 1                   │
                    │      │  })                           │
                    │      └──────────────────────────────┘
                    │                   │
                    │                   ▼
                    │      ┌──────────────────────────────┐
                    │      │  Create Knowledge Node      │
                    │      │  addArtifact({               │
                    │      │    type: "knowledge",        │
                    │      │    data: knowledgeData       │
                    │      │  })                          │
                    │      └──────────────────────────────┘
                    │                   │
                    │                   ▼
                    │      ┌──────────────────────────────┐
                    │      │  Cache Document              │
                    │      │  cacheRagDoc(id, data)       │
                    │      │  └─ Check cache limit        │
                    │      │  └─ Evict oldest if needed   │
                    │      └──────────────────────────────┘
                    │                   │
                    └─────────┬─────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Focus Node                                          │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  focusAndCenter(nodeId)                                  │   │
│  │  └─ Center node in viewport                              │   │
│  │  └─ Highlight with border/glow                           │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Cache Stats Update                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  recordRagDocCacheHit() or recordRagDocCacheMiss()       │   │
│  │  └─ Update hit rate calculation                          │   │
│  │  └─ Display in bottom-right panel                        │   │
│  └──────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
