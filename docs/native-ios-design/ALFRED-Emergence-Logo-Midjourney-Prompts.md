## Technical Notes for Midjourney v7

### Parameter Explanations

| Parameter   | Value               | Reason                           |
| ----------- | ------------------- | -------------------------------- |
| `--ar 1:1`  | Square              | Required for 1024×1024 app icon  |
| `--s 25-75` | Low-mid stylization | Keeps output clean and geometric |
| `--v 7`     | Latest version      | Best for precise graphic design  |

### Post-Processing Workflow

1. **Generate** at default resolution with prompt
2. **Upscale** the best result to max resolution
3. **Import to Figma/Illustrator** for vector tracing
4. **Refine** stroke weights to exact 1.5pt
5. **Export** as:
   - SVG (scalable source)
   - PNG @1x (1024×1024)
   - PNG @2x (2048×2048)
   - PNG @3x (3072×3072)

### Color Values for Final Export

```
Background:  #000000 (void.absolute)
Strokes:     #FCFCFC (biolum.full)
Glow (optional): #FCFCFC at 10% opacity, 20px blur
```
